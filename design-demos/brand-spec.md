# Hypit 品牌资产与用法

> 来源：官方仓库 `hypit-ai/hypit` 的 `docs/public/`，2026-11-11 拉取。资产存在 `design-demos/assets/`。

## 拿到的东西

| 资产 | 文件 | 用途 |
| --- | --- | --- |
| 字标（深色版） | `assets/hypit-logo-dark.svg` | 浅底使用 |
| 字标（浅色版） | `assets/hypit-logo-light.svg` | 深底使用 |
| favicon | 未取到（仓库无此文件，404） | 用图标位自绘 |

两个文件的命名是「为哪种底色准备」的意思，不是颜色的意思：`dark` 供浅底，`light` 供深底。

## 色彩

Logo 只有一套渐变，没有公开的品牌规范页：

```
渐变起点  #e83f5f
渐变终点  #f1738c
纯色近似  #e94765
```

- 这三个值是从 SVG 的 `linearGradient` / 填充里读出来的实测值，不是猜的。
- 无官方二级色、无官方中性色阶。三个方向各自推导中性色，**只把粉色当品牌锚点**，不当主题色铺满。
- 深色方向把粉色压到「选中项 / 主行动」两处；浅色方向同理，避免整屏粉。

## 使用规则

1. 字标高 ≥ 16px 使用；低于此尺寸用图标位（工作台图标）代替。
2. 深底用 `-light` 文件，浅底用 `-dark` 文件；不要给 SVG 加滤镜改色。
3. 不重绘、不拉伸、不加描边或投影。
4. 产品名统一写 `Hypit`（首字母大写），不写 HYPIT、hypit.ai（除链接外）。
5. 我们的插件是第三方工作台，标题写「Hypit 视频工作台」，不冒用官方产品名做主标题。
